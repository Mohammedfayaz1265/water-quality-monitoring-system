# 💧 Water Quality Monitoring System

**Monitor. Analyze. Protect.**

A web-based Water Quality Monitoring System developed as an academic Software Engineering project. It helps users maintain water-quality records, analyze important parameters, identify abnormal readings, and generate alerts through an interactive dashboard.

## 🎯 Project Objective

The main objective is to simplify water-quality record management by replacing manual record maintenance with an organized digital system.

## ✨ Key Features

- **Interactive Dashboard:** View sample statistics and water-quality summaries.
- **Sample Management:** Add, edit, delete, and view water-quality records.
- **Parameter Analysis:** Monitor pH, turbidity, dissolved oxygen, and temperature.
- **Automatic Classification:** Identify readings outside configured thresholds.
- **Alert Management:** Generate and manage alerts for abnormal readings.
- **Analytics:** Visualize water-quality trends through charts.
- **Station Management:** Maintain monitoring station information.
- **Reports:** Generate summaries and export sample records as CSV.
- **Role-Based Views:** Administrator, Analyst/Operator, and Viewer.
- **Data Persistence:** Maintain application data using browser local storage.

## 🧪 Water Quality Parameters

| Parameter | Description |
| --- | --- |
| pH | Measures acidity or alkalinity |
| Turbidity | Measures water cloudiness |
| Dissolved Oxygen | Measures oxygen present in water |
| Temperature | Measures water temperature |

The prototype uses configurable demonstration thresholds. These values are illustrative and should not be treated as official drinking-water safety standards.
